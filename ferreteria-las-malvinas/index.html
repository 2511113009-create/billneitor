Las Malvinas

Un catálogo de materiales eléctricos y herramientas conectado con el trabajo de caja e inventario en tienda.

Del catálogo al recojo

El cliente busca por producto o código, arma su carrito y descarga la constancia de su pedido. La tienda identifica la compra con el mismo código al momento del recojo.

El sistema de la ferretería

El proyecto combina un catálogo web, una aplicación de Windows y una base de datos SQL Server para consultar pedidos, revisar pagos y registrar ventas.
